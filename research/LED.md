It was not clear from the start if it made sense to use an LED or if it made more sense to use a Laser since it's is more stable in performance. 

LED
	- is cheaper
	- is smaller - can  directly be moved into the WOM
	- is not as stable as a laser
	- can be pulsed but can also operate in a continuous mode with high power for the [[Absorption measurement]]
		- Needs a [[Pulsgenerator ]]
	- should be monitored continuously


The LED is the Broadcom® 3W 3535 Surface Mount UV LED AUV3-SQ32-0RT0K
365nm LED that has a very high power
