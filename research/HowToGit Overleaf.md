In Overleaf premium you can easily connect your project with github and thereby with VScode 

When you are in your project in Overleaf 
1. Klick **Menu**
2. Under Sync klick **GitHub** - log into your github and follow the instructions 
3. Open VScode and the folder where you want the project in terminal execute
```
git clone <link to your overleaf project in github>
   ```
   f.e. `https://github.com/idawoestheinrich/Master_thesis__Woestheinrich_628428`
There are some extensions in VScode that support LaTeX, but I have not figured how to execute them yet.
