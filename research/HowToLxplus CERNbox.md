CERNBox files are stored in EOS (the disk-based storage service), which is mounted by default in **lxplus**

Therefore, on a lxplus shell, do the following: 

`% cd /eos/user/<initial>/<username>`
```shell
cd /eos/user/i/idwoesth
```

new: 
```shell
eos/home-i/idwoesth/
```

to access your user directory in CERNBox.
