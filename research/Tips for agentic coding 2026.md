###### Usage limits [Page 6](zotero://open-pdf/library/items/YEPT6N7F?page=6&annotation=2846ZKB5)
- Token is basically ~1 symbol LLM reads/produce and it costs some computational  power and thus electricity & money (of the LLM owner). [Page 6](zotero://open-pdf/library/items/YEPT6N7F?page=6&annotation=SN4QFYQV)
- For the 20 euros version, there are 2 limits: for the current session and for the week.  The first is updated every 5 hours. [Page 6](zotero://open-pdf/library/items/YEPT6N7F?page=6&annotation=5HAZXA7L)
- The less you know about the task/code base (the more you vibe code), the faster it runs  out [Page 6](zotero://open-pdf/library/items/YEPT6N7F?page=6&annotation=LKJPRUCK)
- Do not approve all it wants to do: you can commit, test and build the software by  yourself [Page 6](zotero://open-pdf/library/items/YEPT6N7F?page=6&annotation=H3HM55TC)
- Keep an eye what is does: sometimes it starts investigating unrelated directories. Stop  it and explain where to work. [Page 6](zotero://open-pdf/library/items/YEPT6N7F?page=6&annotation=G87V7Z5R)

###### Recommended usage [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=NNDNBMQG)
- 1. You have a plan in your head of implementing some feature [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=3GKW4ARK)
- 2. Turn the planning mode (shift+tab) and explain to Claude what you want [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=H53GJRL2)*The planing mode is very good to better understand what you want to do. CHECK THE PLANS. You can edit the plan and correct it and tell it to review the plan again.* [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=H53GJRL2)
- how  it should look like [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=E3K7PZIH)
- what should you expect in the end [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=DJIL4MLQ)
- Specify the files you want to modify via @file_address [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=DDK6MGVA)*brief discription of what the file is - so that it does not have to read the whole file* [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=DDK6MGVA)
- Ask Claude to interview you [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=68ZLZ97S)*If needed, so that you understand better what is needed* [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=68ZLZ97S)
- 3. Once it created the plan, thoroughly check what is happening to stay in  context. [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=78SU2JB6)*Any plan is a markdown file so you can edit it.  It also can make sense to make an overall plan and then solve that plan step by step* [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=78SU2JB6)
- 4. Optional: if the plan is very complicated, open another claude shell and ask to  check the created plan on possible issues. [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=YSNMZTIY)
- 5. Modify the plan if needed and push the huge ENTER button. [Page 7](zotero://open-pdf/library/items/YEPT6N7F?page=7&annotation=J8G3Z5WY)

###### Drawbacks of using Claude Code [Page 13](zotero://open-pdf/library/items/YEPT6N7F?page=13&annotation=ZSGNLURH)
- your own skills get `stagnated` (discussive!) [Page 13](zotero://open-pdf/library/items/YEPT6N7F?page=13&annotation=DQWMV28B)
- it has a drug-like effect because of the limited number of tokens per session [Page 13](zotero://open-pdf/library/items/YEPT6N7F?page=13&annotation=8FNKLWAL)
- it works way worse when you don’t really understand the technology you are  working at (like working on cpp project, when you’ve never touched cpp) [Page 13](zotero://open-pdf/library/items/YEPT6N7F?page=13&annotation=M37BTSA5)*Foccuss on educational stuff* [Page 13](zotero://open-pdf/library/items/YEPT6N7F?page=13&annotation=M37BTSA5)
- it’s just LLM – sometimes it is extremely stupid, especially when it tries to  wrap physics on top of the project base. [Page 13](zotero://open-pdf/library/items/YEPT6N7F?page=13&annotation=3T3UD5DI)
