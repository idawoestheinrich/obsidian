### Trackpad
Swipe between pages - **scroll with two fingers**
Swipe between full-screen applications - **scroll with three fingers**
Notification Center - **Swipe to the left from the upper right corner**
Mission contoll - Overview over all windows - **swipe up with three fingers**
Launchpad - shows all applications - **pinch with three fingers and thumb**
Show Desktop spread up with - **pinch with three fingers and thumb**

### Safari
New tab -  **command T**
New Window - **command N**
New Empty Tab Group - **shift command N**

Close tab or window - **command w**

Swich between tabs - to the right - **control tab**
				 - to the left - **contol shift tab**
Swich between tab groups  - previous - **command shift up**
					   -  next  - **command shift down**

To go to a numbered Tab - **command 1-9**, where 1 is the first and 9 is the last 

Open link in a new tab - **command click**
Open link in a new tab and make it aktive - **command shift click**
Open link in a new window - **command option click**
Open link in a new window and make it aktive - **command shift  option click**

Reopen the last tab that you closed down - **Shift Command T**

To add bookmarks - **command d**
Show or hide bookmarks - **command shift b**
Add to Reading List - **command shift D**

Search for something in the search bar - **Command option F** 

Go back to the search results - **Command option S**

to pin a tab - **Window pin tab**
