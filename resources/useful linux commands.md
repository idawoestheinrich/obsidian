`cd <path/to/directory>` - if nothing is given - home directory
`ls <path/to/directory>` - view content of the given directory
`makedir <new/directory>` - make new directory
`rm <file>` - remove file
`pwd` -path to  your current directory
`nano <file>` -gives you a simple editor to view and edit files
`cat <file>` -prints a file into terminal 
`echo "<some text>"`-  print to terminal
`echo "<some text>" > test-file.txt`-  creates/overwrites file with content some text
`echo "<some text>" >> test-file.txt`-  adds content some text to file
and creates the file if it doesn't exist already
`python example.py` opens python file
`python` opens python environment
`root` open root environment 
`rootbrowse <file>` open the file in root browser (slow when used in lxplus, better VScode with the [ROOT File Viewer](https://marketplace.visualstudio.com/items?itemName=albertopdrf.root-file-viewer)
